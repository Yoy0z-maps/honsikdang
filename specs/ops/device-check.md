# 실기기 점검표 (WP-07, 약 15분)

미리보기 배포 주소로 휴대폰에서 확인합니다. 문제가 있으면 항목 번호와 기기·브라우저를 알려 주세요. 스크린샷이 있으면 더 좋습니다.

- 기기: ☐ iPhone (Safari) ☐ Android (Chrome)

| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | 주소를 열기 | 지도가 바로 화면 전체에 보이고, 위·아래 안전 영역(노치)에 가려지는 버튼이 없음 |
| 2 | 위치 허용 / 거부 각각 | 처음 열 때 위치를 물음. 허용: 내 위치에서 파란 점·정확도 원과 함께 열림. 거부: 마지막으로 본 지역, 처음이면 서울역에서 열리고 지도·목록 사용 가능 |
| 2a | 허용한 채로 걷기, 지도를 손가락으로 끌기, ◎ 누르기 | 걷는 동안 파란 점과 지도가 따라옴. 끌면 따라가기가 멈추고, ◎를 누르면 다시 따라감. 화면을 끄면 위치 사용이 멈춤(배터리) |
| 2b | 장소 제안에서 식당 이름 검색 → 결과 선택 | 이름·주소·음식 종류가 채워지고 핀이 그 식당으로 이동. 칸은 고칠 수 있음 |
| 3 | 지도 이동·확대, "이 지역에서 다시 검색" | 손가락 동작이 자연스럽고 목록이 바뀜 |
| 4 | 하단 목록을 끌어 올리기/내리기 | 접힘·반·전체가 잘 멈추고, 지도가 같이 움직이지 않음 |
| 5 | 마커 누르기 → 미리보기 → 상세 보기 | 카드가 하단에 뜨고 상세로 이동 |
| 6 | 검색창 입력 | 키보드가 입력칸을 가리지 않음 |
| 7 | 상세의 길찾기 | 네이버 지도 앱이 열려 도보 길찾기(목적지만). 앱이 없으면 스토어로 이동 |
| 8 | 로그인 메일 | 1분 안에 메일이 오고(스팸함 확인), 링크를 누르면 로그인 상태로 돌아옴 |
| 9 | 리뷰 쓰기(30초 이내) | 키보드·선택지가 불편하지 않음 |
| 10 | 저장 → 내 활동 → 저장 탭 | 목록에 보이고 해제 가능 |
| 11 | "오늘 뭐 먹지?" | 버튼이 스크롤 없이 보이고, 추천 3곳과 번호 마커 |
| 12 | 개인정보처리방침·이용약관 | 읽을 수 있고 표가 화면 밖으로 넘치면 표 안에서만 옆으로 밀림 |
| 13 | 다크 모드(기기 설정) | 글자가 배경에 묻히지 않음 |
| 14 | 홈 화면에 추가(선택) | 열리긴 하지만 설치형 앱 기능은 아직 없음(PWA 미정) |
