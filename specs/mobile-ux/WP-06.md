# WP-06 모바일 UX 수락 보고서

- 대상: "오늘 뭐 먹지?" 칩, 하단 시트 추천 모드(조건 칩, 번호 추천 카드, 패스·다른 추천 보기, 추천 기준), 지도 마커 번호 (master plan v0.2 §5A, FR-013)
- 날짜: 2026-10-19
- 환경: Playwright Chromium (Pixel 7 UA, 터치) 360×800 / 390×844, 프로덕션 빌드, 로컬 Supabase + 합성 시드(지도 안 8곳), 로그인 없음
- 스크린샷: `specs/mobile-ux/screenshots/WP-06-mobile-{360,390}-{1-inputs,2-picks,3-shortfall}.png`

## 1. 기준별 결과

| 기준 | 결과 | 근거 |
|---|---|---|
| 지도 위에서 진행(별도 피드 없음), 지도 마커에 번호 | ✅ | 하단 시트 모드, 마커 라벨 1·2·3 |
| 추천 버튼이 스크롤 없이 보임(360) | ✅ | e2e: 버튼 전체가 화면 안 |
| 결과가 먼저 보임 | ✅ | e2e: 1번 추천이 바로 화면 안, 조건은 한 줄 요약 |
| 서로 다른 종류 3곳, 이유는 저장된 값만 | ✅ | e2e: 종류 3가지, 이유 문장이 정해진 형식만 |
| 예산·제외 조건 위반 없음 | ✅ | e2e + 단위 테스트(무작위 200묶음) |
| 3곳 미만·0곳일 때 이유 설명 | ✅ | e2e: "이미 본 추천은 다시 보여 주지 않아요 · 지도를 옮기거나 넓혀 보세요" |
| 44px 터치 영역, 가로 넘침 없음 | ✅ | e2e |
| 로그인 없이 사용 | ✅ | 모든 e2e가 비로그인 |

## 2. 스크린샷 검토 메모

| 화면 | 확인 내용 | 조치 |
|---|---|---|
| 조건 입력 | 음식 종류 칩 18개(먹고 싶은/빼고)가 펼쳐져 추천 버튼이 시트 맨 아래로 밀림 | 종류 선택을 접기(W6-03) |
| 추천 결과 | 실행 뒤에도 조건 양식이 위에 남아 결과가 화면 밖 | 실행 뒤 조건을 한 줄 요약으로 접기(W6-03) |
| 360 조건 입력 | 예산 칩이 두 줄이 되어 버튼이 17px 화면 밖 | 칩 표시를 "7천 원" 형식으로(W6-04) |
| 추천 카드 | 번호·종류·"가격 정보 없음"이 한눈에 보임 | — |
