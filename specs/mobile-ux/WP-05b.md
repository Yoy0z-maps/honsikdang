# WP-05b 모바일 UX 수락 보고서

- 대상: AI 검색의 선호 표현 안내, 결과 목록의 "관련도순" 표시와 "거리순" 전환, 비로그인 시 거리순 안내 (master plan v0.2 §5A, §8)
- 날짜: 2026-10-16
- 환경: Playwright Chromium (Pixel 7 UA, 터치) 360×800 / 390×844, 프로덕션 빌드, 로컬 Supabase + 합성 시드, **테스트 대역 해석기·임베딩** — 실제 모델 아님
- 스크린샷: `specs/mobile-ux/screenshots/WP-05b-mobile-{360,390}-{1-ai-semantic,2-relevance-list}.png`

## 1. 기준별 결과

| 기준 | 결과 | 근거 |
|---|---|---|
| 순서 기준을 숨기지 않음: 목록 위에 "관련도순 · ‘…’에 가까운 리뷰가 있는 곳부터" | ✅ | e2e, 스크린샷 2 |
| 관련도순은 순서만 바꾸고 결과 수는 그대로 | ✅ | e2e: "식당 8곳" 유지, 1위가 가장 가까운 곳에서 리뷰가 맞는 곳으로 바뀜 |
| 한 번에 거리순으로 돌아가기, 44px | ✅ | e2e: "거리순" → `sem` 제거, 거리순 복귀 |
| AI 검색의 선호 표현을 조건과 구분해 안내 | ✅ | e2e, 스크린샷 1: "‘혼자 먹기 편한’에 가까운 곳부터 보여 줘요." |
| 쓸 수 없을 때(비로그인·키 없음) 거리순과 이유 표시 | ✅ | e2e (비로그인) |
| 가로 넘침 없음 | ✅ | 기존 e2e 확인 항목 유지 |
