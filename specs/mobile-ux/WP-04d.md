# WP-04d 모바일 UX 수락 보고서

- 대상: 상세의 길찾기·저장, 지도 미리보기의 길찾기, `/me/saved`와 "내 활동" 탭, 앱 없는 환경 안내 (master plan v0.2 §5A)
- 날짜: 2026-10-15
- 환경: Playwright Chromium (Pixel 7 UA, 터치) 360×800 / 390×844, 프로덕션 빌드, 로컬 Supabase + 합성 시드. 앱 없는 환경은 데스크톱 UA로 확인
- 스크린샷: `specs/mobile-ux/screenshots/WP-04d-mobile-{360,390}-{1-preview-directions,2-detail-saved,3-activity-saved,4-activity-places,5-no-app-guidance}.png`

## 1. 기준별 결과

| 기준 | 결과 | 근거 |
|---|---|---|
| 길찾기는 목적지만 전달하고 사용자 위치는 보내지 않음 (Q33) | ✅ | e2e: Android 링크의 `dlat`·`dlng`·`dname`·`appname` 값, `slat` 없음. Vitest로 iOS·데스크톱 분기 |
| 앱이 없으면 스토어로 (Android 자동, iOS 시간 대체) | ✅ 설계 | intent URL에 패키지명, iOS는 1.5초 뒤 화면이 그대로면 App Store. 실기기 미확인(K-32) |
| 데스크톱·앱 없음: 안내 + 주소 복사, 추측한 웹 URL 없음 (Q34) | ✅ | e2e: 안내 문구, 복사 후 클립보드 값 확인 |
| 저장은 상세에만, 미리보기는 길찾기 + 상세 보기 (Q35) | ✅ | e2e·스크린샷 1 |
| 로그인 안 했으면 로그인 후 같은 상세로 복귀 | ✅ | e2e |
| 저장 → 새로고침 후 유지 → 내 활동 › 저장 → 해제 | ✅ | e2e, `aria-pressed`로 상태 노출 |
| "내 활동" 탭, 현재 탭 `aria-current` (Q36) | ✅ | e2e |
| 44px 터치 영역, 가로 넘침 없음 | ✅ | e2e: "← 목록으로"(K-31)·길찾기·저장 44px 이상, 상세·저장 목록·안내 화면 가로 넘침 없음 |
