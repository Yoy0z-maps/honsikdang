# WP-05c 모바일 UX 수락 보고서

- 대상: 관련도순 결과 카드와 지도 미리보기의 근거 인용, "근거 없음" 표시, 상세 화면의 해당 리뷰 강조 (master plan v0.2 §5A, FR-012)
- 날짜: 2026-10-16
- 환경: Playwright Chromium (Pixel 7 UA, 터치) 360×800 / 390×844, 프로덕션 빌드, 로컬 Supabase + 합성 시드, 테스트 대역 임베딩
- 스크린샷: `specs/mobile-ux/screenshots/WP-05c-mobile-{360,390}-{1-evidence-list,2-evidence-review}.png`

## 1. 기준별 결과

| 기준 | 결과 | 근거 |
|---|---|---|
| 인용은 승인 리뷰 원문 그대로, 출처(방문일) 표시 | ✅ | e2e: 시드 리뷰 문장과 정확히 일치, "방문 2026.10.07 리뷰에서 그대로 가져왔어요" |
| 근거가 없으면 지어내지 않고 "아직 없어요" | ✅ | e2e: 리뷰 본문이 없는 식당 |
| 인용을 누르면 상세의 해당 리뷰로 이동·강조 | ✅ | e2e: URL 해시, 리뷰가 화면 안(90% 이상), 강조 표시 |
| 인용 링크 44px | ✅ | e2e |
| 동작 줄이기 설정 존중 | ✅ 설계 | `prefers-reduced-motion`이면 즉시 이동 |

## 2. 스크린샷 검토 메모

| 화면 | 확인 내용 | 조치 |
|---|---|---|
| 상세 이동 | 해당 리뷰가 강조되지 않고 화면 아래 끝에 걸림 | 클라이언트에서 가운데로 스크롤·강조(W5c-04) 후 재촬영 |
| 목록 카드 | 인용이 카드 하단에 주황 선으로 구분되어 요약 정보와 섞이지 않음 | — |

| 항목 | 확인 방법 |
|---|---|
