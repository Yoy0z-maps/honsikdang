# WP-07 모바일 UX 수락 보고서 (출시 준비, 코드 부분)

- 대상: 로그인 화면 동의 안내, 개인정보처리방침·이용약관, 계정 관리(삭제), 삭제 완료 화면, 내 활동의 계정·정책 링크 (master plan v0.2 §5A, §11)
- 날짜: 2026-10-19
- 환경: Playwright Chromium (Pixel 7 UA, 터치) 360×800 / 390×844, 프로덕션 빌드, 로컬 Supabase
- 스크린샷: `specs/mobile-ux/screenshots/WP-07-mobile-{360,390}-{1-login-consent,2-privacy,3-privacy-table,4-account}.png`

## 1. 기준별 결과

| 기준 | 결과 | 근거 |
|---|---|---|
| 로그인 전에 약관·방침 링크 노출 | ✅ | e2e: 로그인 화면 → 개인정보처리방침 이동 |
| 정책 문서가 휴대폰에서 가로 넘침 없이 모든 항목 보임 | ✅ | e2e(가로 넘침 0) + 스크린샷: 표를 카드로 |
| 계정 삭제 전 결과 설명(익명화 포함)과 실수 방지 | ✅ | "삭제" 입력 확인, 틀리면 안내(e2e) |
| 삭제 후 로그아웃·개인 화면 접근 차단 | ✅ | e2e: 완료 화면 → 저장 목록 접근 시 로그인 요구 |
| 44px 터치 영역 | ✅ | 링크·버튼 `min-h-11` |

## 2. 스크린샷 검토 메모

| 화면 | 확인 내용 | 조치 |

| 개인정보처리방침 표 | 360px에서 보유 기간·국가 열이 잘리고 가로 스크롤인지 알기 어려움 | 휴대폰에서는 행마다 카드로 표시(W7-03) 후 재촬영 |
| 계정 관리 | 삭제 결과 3가지와 빨간 버튼이 분명함 | — |
